# 놀이터 게임 모음 (game)

유아·초등 저학년용 미니게임 모음. 한 페이지 안에서 게임을 골라 한다. AIEDU 허브(`arenarun23/aiedu`)의 하위 서비스로 `/game/` 경로에 붙는다.

- 정적 파일만 사용(빌드·서버·API 키 없음), **상대경로만** 사용 → 허브 하위 경로에서도 동작
- 게임 6개, 각각 **20가지 종류**(총 120가지)와 **쉬워요/어려워요** 두 가지 난이도 (+ 🧩 미로찾기, 🏁 레이싱은 아래 따로)
  - 위쪽 막대의 🔄 **새로 하기**: 같은 게임의 다른 종류(20가지를 섞어서, 한 바퀴 돌 때까지 겹치지 않음)
  - 난이도는 아이가 직접 고른다(기억해 둠). 어려움은 클리어 시 별 +1

| 게임 | 쉬워요 | 어려워요 | 20가지 |
|---|---|---|---|
| 색칠하기 | 마음대로 칠하기 | 세부 칸이 늘고 **견본과 똑같은 색**으로만 칠해짐 | 그림 20종 |
| 점 잇기 | 점 5~12개 + 점선 안내 | 점이 더 많고 안내 없음 | 모양 20종 |
| 짝 맞추기 | 3~6쌍, 처음에 잠깐 보여 줌 | 6~12쌍, 미리 보기 없음 | 주제 20종 |
| 다른 것 찾기 | 4~9칸, 차이가 큼 | 9~20칸, 차이가 작음 | 종류 20종(그림·색·방향·크기·개수·숫자·글자 등) |
| 두더지 잡기 | 9칸, 느림, 방해꾼 적음 | 12칸, 빠름, 방해꾼 많음 | 규칙 20종(목표 동물, 피할 것, 이름 대면 눌러요, 짝수만 등) |
| 분류하기 | 상자 2개, 그림 6개 | 상자 3개, 그림 10~12개 | 주제 20종 |

### 🧩 미로찾기 (`js/games/maze.js`, 음악 `js/maze_music.js`)
손가락(드래그·옆 칸 누르기)이나 방향키로 길을 따라 짝꿍(🐭→🧀 등 8가지)에게 가는 미로. 위 표의 20가지 구조와 달리 **자기 메뉴**(`noSub: true` — 공통 난이도 막대를 쓰지 않는다)를 가진다.
- **난이도 3단계**(위쪽 막대가 아니라 게임 안 메뉴, 저장 키 `game:maze-level`): 쉬워요 / 어려워요 / 매우 어려워요. 별 보너스 +0/+1/+2(`G.win({bonus})`).
- **맵은 판마다 다르다**: 테두리 7가지(사각형·원·삼각형·마름모·오각형·육각형·하트) × 만드는 방식 3가지(구불구불·갈래갈래·방방이) × 짝꿍 8가지(벽·바닥 색도 다름). 출발·도착은 길로 가장 먼 두 칸. 가로 화면은 왼쪽 세로 메뉴 + 오른쪽 큰 미로, 세로 화면은 위쪽 메뉴.
- **방해꾼**(모든 단계, 닿으면 처음부터 다시): 쉬움 2~3마리 / 어려움 5~6 / 매우 어려움 7~8. 🐛 떠돌이, 🕷️ 길목 지킴이(갈림길에서 옆길을 드나들며 길을 막는다), 🦂 추적자(가까우면 쫓아옴). 길로만 다니고 도착 칸·출발 칸 둘레 2칸에는 못 들어온다. 부딪힌 직후 1.5초 무적, 3번 이상 부딪히면 별 −1.
- **음악**(`G.mazeMusic`, 레이싱 음악 `G.music` 과 별개): 웹오디오로 직접 연주하는 칩튠. 쉬움 4곡·어려움 4곡이 끊김 없이 이어지고, 매우 어려움은 1.1배 빠름. 🎵 버튼으로 음악만 끌 수 있다(저장 키 `game:maze:music`).
- 2026-11-07 단독 서비스 `arenarun23/miro`(허브 카드)에서 이 모음으로 옮겼다. 허브의 `/miro/` 주소는 `/game/#maze` 로 연결된다.

### 🏁 레이싱 (`js/games/race.js`, 데이터 `race_data.js`)
마리오 카트 같은 아이템 레이스를 **직접 만든 캐릭터·차·경기장**으로 구현(원작의 캐릭터·이름·그림은 쓰지 않는다).
- 위에서 내려다보는 2D, 카메라가 내 차를 따라 돈다. 자동 가속, ◀▶ 로 조종(키보드: ←→ / A D)
- **캐릭터 8**: 토토(가속·점프 대시), 곰곰이(튼튼·방패), 여우리(핸들·함정), 펭구(얼음길 무시·얼음 발사), 레오🦁(더 센 부스트·사자 포효), 코코🐘(앞 차를 밀치며 돌파·땅 구멍), 치타🐆(엄청 빠름·번개 질주), 호랑이🐯(힘이 세고 안 흔들림·발톱 할퀴기: 앞의 가까운 차를 빙글)
- **차 8**: 번개호(속도·터보), 튼튼이(풀밭·충격파), 미끄리(커브·기름 웅덩이), 든든이(출발·아이템 뽑기), 빵빵이🚌(아주 무거움·급행 출발), 폴짝이🚕(점프 추월: 뛰는 동안 다른 차·함정을 넘어감), 순찰이🚓(핸들·사이렌: 바로 뒤 차들을 빙글), 소방이🚒(튼튼·물대포: 앞 차들을 밀어 느리게)
- 스킬 2개(캐릭터 + 차, 각각 쿨타임) + 아이템 상자(🍄부스트 🛡️방패 🍌바나나 🎯미사일). 키보드: Z / X / Space
- **경기장 16 (이지 8 + 하드 8, 모양이 모두 다름)** — 모드를 바꾸면 경기장 목록이 바뀐다. 곳마다 부스트 패드·느려지는 곳·얼음판이 다름
  - 이지(넓은 길): 콩, 8자(교차로), ㄴ자, 땅콩, 클로버, T자, 화살촉, ㄷ자
  - 하드(좁은 길·급커브): 지그재그, 꼬인 8자, 별, 물결, 하트, 계단, G자, 세잎 매듭(교차 3곳)
  - **🧊 3D 경기장: 모드마다 12개 — 이지 12 + 하드 12** — 차 뒤에서 따라가는 원근 3D 시점(`js/games/race3d.js`, 캔버스로 직접 그림·외부 라이브러리 없음). 언덕(오르막은 느리고 내리막은 빠름), 점프대(공중에선 조종이 약함), 다리(8자·매듭은 위아래로 겹치고 위아래 차는 부딪히지 않음). 먼 곳은 안개에 묻히고 길·물체는 먼 것부터 그려 가림이 맞다.
    - 이지 3D: 구름 언덕(둥근 사각), 모래 언덕(세 갈래), 놀이공원 고가(8자 다리), 눈 롤러코스터(ㄴ자), 해변 고갯길(고래), 도시 고가(십자), 화산 고갯길(반달), 우주 활주로(물방울)
    - 하드 3D: 용암 롤러코스터(급경사), 밤의 고가 8자, 우주 매듭 다리(교차 3곳 모두 다리), 초원 산등성이(W자), 협곡 고리(안쪽 고리가 다리), 눈꽃 정상(6각), 톱니바퀴 언덕, 파도 절벽
    - 경기장 선택 화면은 **2D / 3D 탭**으로 나뉜다. "다음 경기" 시리즈와 하드 도전 질문은 탭 단위(2D 12개, 3D 12개)로 이어진다.
    - 정의: `TRACKS_*` 에 `T3(...)` — 길 모양 + 높이 곡선(`h0 + Σ A·sin(2π·k·u + φ)`, u = 한 바퀴 0~1) + 점프대(`haz.jump`, 가장 곧은 구간에 자동 배치). 새 3D 경기장을 만들면 최대 경사(≈15° 이하)와 겹침 구간의 높이 차(차 높이보다 충분히 크게)를 꼭 검사한다.
- **음악·효과음** (`js/music.js`, 파일 없이 웹오디오로 직접 연주): 경기장 8곳마다 곡이 다르고(음계·빠르기·악기·드럼 패턴), 하드 모드는 약 10% 더 빠름. 출발 카운트다운(3·2·1 삐 → 출발 팡파르)과 골인 축하 소리(등수별)가 있다. 🔊 로 끄면 음악도 꺼지고, 🎵 칩은 음악만 끈다. 사용법 화면이나 다른 탭에서는 잠깐 멈춘다.
  새 곡은 `THEMES` 에 bpm·root(으뜸음)·scale·prog(코드)·rhythm·드럼 패턴을 적으면 멜로디가 자동으로 만들어진다. `G.music.render(이름, 하드, 초)` 로 소리 없이 만들어 음량·조를 분석할 수 있다.
- **별 보상(🏅 내 보상, 놀이터에서 모은 별(상단 ⭐)로 열린다)**: 별 50(칭호·트로피) / 100(차 색 5가지) / 200(꼬리 효과: 별·하트·무지개) / 500(캐릭터 모자, 칭호 「레이싱 왕」) / 1000(황금 차, 칭호 「전설의 레이서」). 고르기 화면의 🏅 내 보상에서 확인·꾸미기를 고르고, 📸 사진 저장으로 보상 화면을 PNG로 보관하고, 🔁 옮기기로 다른 기기에 코드·파일로 옮긴다(서버·기기 식별 정보 없이 별·꾸미기·완주 기록만)(바로 내려받기로 저장). 코드: `js/games/race_reward.js`
- **경기장 수**: 이지·하드 각각 2D 12개 + 3D 12개(🐣 아주 쉬워요는 이지와 같은 맵). 새 맵: 이지 꽃 동산·나비 정원(2D), 병아리 언덕·하트 고개(3D) / 하드 물고기·H자 서킷(2D), 별 능선·지붕 능선(3D). 2차: 이지 얼음 모퉁이·구름 호수(2D), 별빛 언덕·콩밭 고개(3D) / 하드 E자·S자 서킷(2D), 나비 능선·네잎 능선(3D).
- **우주 음악 6곡**(`music.js` moon·mars·europa·titan·io·ceres; 타이탄=안개 낀 신비, 이오=쿵쿵 화산, 세레스=무중력 통통)  — 앞의 3곡:: 달=느리고 둥실(84BPM, 사인 선율+메아리), 화성=행진하는 탐사차(124BPM, 톱니파 베이스·드럼), 유로파=얼음 종소리 반짝이(96BPM, 높은 종+패드). 하드는 1.1배 빠름.
- **우주 사실감**: 공기 없는 곳은 까만 하늘·은하수·태양 눈부심·안개 거의 없음, 햇빛 방향에 따른 밝은 면·그림자, 직접 그린 안테나·착륙선·거주 모듈·태양전지판·통신탑, 어두운 아스팔트+흰 도색 선, 금속 가드레일, 바퀴 먼지 꼬리(중력 약할수록 오래), 렌즈 가장자리 어둡게(`race3d.js` drawProp·sunR/sunF).
- **우주 코스 꾸밈**: 크레이터·모난 바위·얼음 기둥·안테나, 모난 먼 산, 하늘의 지구/화성 위성/목성, 네온 연석, 빛의 울타리(반투명 벽), 운전석 유리 돔(`race3d.js` `SPC`).
- **아이템 카드 4칸**: 맵의 아이템 상자는 한 줄에 4개씩, 차는 카드를 최대 4장 보관한다(오른쪽 카드 칸을 눌러 사용, 키보드 1~4·Space=첫 카드, 칸이 차면 상자를 못 줍는다). **경기 화면 크게**: 달리는 동안 위쪽 모드 버튼 줄을 숨기고(높이 700px 이하) ⛶ 전체 화면 버튼(지원 브라우저)을 둔다.
- **3D 시점**: 카메라를 내 차 뒤로 1.5배 멀리(`race3d.js` 맨 위 `VIEW = 1.5`, 1이면 예전 거리).
- **🚀 우주 탭**(2D·3D 옆 세 번째 탭): 달 기지·화성 협곡·유로파 얼음·타이탄 늪·이오 화산·세레스 소행성 서킷 6곳(3D, 이지/하드/아주 쉬워요 모두 같은 맵, 바퀴 수는 모드대로 1/2/3바퀴). 행성마다 **중력**이 달라 점프 시간·높이가 달라지고(달 1.62·화성 3.71·유로파 1.31·타이탄 1.35·이오 1.8·세레스 0.28, 점프 배율 상한 2.4), 먼지·모래·서리 **구간**에서는 느려진다(풀밭에 강한 캐릭터·차는 덜 느려지고, 펭구는 유로파 서리에서 안 미끄러움). **옵션**(우주 탭에서만, 저장됨): 🌪️ 후반 날씨(2바퀴째부터 도로 전체가 덮임) · 🛞 바퀴 고르기(암반/겸용/먼지용 + 경기 중 칩을 눌러 피트 예약 → 출발선 앞에서 멈춰 2.5초 교체). 코드: `race_data.js`(SPACE_PTS·mkSpace), `race.js`(SP·TIRES), `race3d.js`(먼지 색·별·날씨 안개).
- **시리즈**: 경기가 끝나면 "다음 경기를 할까요? ✅네 / ❌아니요"를 묻는다(네 → 같은 캐릭터·차로 다음 경기장, 아니요 → 처음 화면). 완주한 경기장은 모드별로 저장되어 선택 화면에 ✅ 와 진행도(3/8)로 보인다. 이지 8개를 모두 달리면 "🔥 어려운 모드에 도전할까요?", 하드 8개까지 끝나면 "이지부터 다시?"를 묻는다.
- 🐣 아주 쉬워요(레이싱 전용): 1바퀴, 상대가 아주 느리고 아이템을 거의 안 쓰며, 도우미가 항상 켜지고 벽이 넓어요. 캐릭터·경기장은 같아요 / 쉬워요: 2바퀴, 상대가 느림 / 어려워요: 3바퀴, 상대가 빠르고 아이템·스킬을 자주 씀. 1등 ⭐3, 2등 ⭐2, 그 외 ⭐1 차는 2D·3D 모두 10% 크게 보이고, 그만두면 레이싱 첫 화면(캐릭터 고르기)으로 돌아가요.
- 트랙은 `race_data.js` 의 `TRACKS_EASY` / `TRACKS_HARD` 에서 꼭짓점(`poly`)·길 너비(`w`)·색(`theme`)·지대(`haz`)로 정의한다. 꼭짓점이 자동으로 부드러운 곡선이 되고, 급커브가 `rmin` 보다 날카로우면 자동으로 펴진다. 새 모양을 추가하면 커브 반지름과 의도하지 않은 길 겹침을 꼭 검사할 것.
- 이미지는 이모지·SVG, 소리는 WebAudio 로 직접 만든다 (외부 에셋·저작물 없음)
- 로컬 확인: `python3 -m http.server 8080` 후 http://localhost:8080/

## 구조
```
index.html            화면 틀(상단 바 + #stage)
css/style.css         공통 스타일 (rem+clamp, 한 화면에 맞춤)
js/core.js            공통: 화면 전환, 소리, 별, 결과 창, 처음 화면(카테고리 탭 + 카드)
js/games/<id>.js      게임 하나당 파일. G.register({id,name,desc,icon,cat,color,variants:20,start(root,{hard,v})})
                      v = 이번에 뽑힌 종류 번호(0~19), hard = 어려움 여부
js/main.js            시작
```

## 게임 추가하는 법
1. `js/games/새게임.js` 작성: `G.register({ id, name, desc, icon, cat: 'draw'|'match'|'play', color: 'pink|sky|orange|mint|lemon|lilac|peach', start(root){ …; return 정리함수 } })`
   - `variants` 에 종류 수를 적으면 코어가 섞어서 `v` 로 넘겨 준다. 격자는 `G.bestGrid(n, box)` 로 정한다.
   - 끝나면 `G.win({ stars: 1~3, text })` 를 부른다. 타이머는 반환하는 정리함수에서 해제한다.
2. `index.html` 에 `<script src="js/games/새게임.js"></script>` 추가 (`main.js` 앞).
3. 카테고리를 늘리려면 `js/core.js` 의 `G.cats`.
