# 놀이터 게임 모음 (game)

유아·초등 저학년용 미니게임 모음. 한 페이지 안에서 게임을 골라 한다. AIEDU 허브(`arenarun23/aiedu`)의 하위 서비스로 `/game/` 경로에 붙는다.

- 정적 파일만 사용(빌드·서버·API 키 없음), **상대경로만** 사용 → 허브 하위 경로에서도 동작
- 게임 6개, 각각 **20가지 종류**(총 120가지)와 **쉬워요/어려워요** 두 가지 난이도 (+ 🧩 미로찾기, 🏁 레이싱은 아래 따로)
  - 위쪽 막대의 🔄 **새로 하기**: 같은 게임의 다른 종류(20가지를 섞어서, 한 바퀴 돌 때까지 겹치지 않음)
  - 난이도는 아이가 직접 고른다(기억해 둠). 어려움은 클리어 시 별 +1

| 게임 | 쉬워요 | 어려워요 | 20가지 |
|---|---|---|---|
| 색칠하기 | 마음대로 칠하기 | 세부 칸이 늘고 **견본과 똑같은 색**으로만 칠해짐 | 그림 20종 |
| 점 잇기 | 점 5~12개 + 점선 안내 | 점이 더 많고 안내 없음 | 모양 20종 |
| 짝 맞추기 | 3~6쌍, 처음에 잠깐 보여 줌 | 6~12쌍, 미리 보기 없음 | 주제 20종 |
| 다른 것 찾기 | 4~9칸, 차이가 큼 | 9~20칸, 차이가 작음 | 종류 20종(그림·색·방향·크기·개수·숫자·글자 등) |
| 두더지 잡기 | 9칸, 느림, 방해꾼 적음 | 12칸, 빠름, 방해꾼 많음 | 규칙 20종(목표 동물, 피할 것, 이름 대면 눌러요, 짝수만 등) |
| 분류하기 | 상자 2개, 그림 6개 | 상자 3개, 그림 10~12개 | 주제 20종 |

### 🧩 미로찾기 (`js/games/maze.js`, 음악 `js/maze_music.js`)
손가락(드래그·옆 칸 누르기)이나 방향키로 길을 따라 짝꿍(🐭→🧀 등 8가지)에게 가는 미로. 위 표의 20가지 구조와 달리 **자기 메뉴**(`noSub: true` — 공통 난이도 막대를 쓰지 않는다)를 가진다.
- **난이도 3단계**(위쪽 막대가 아니라 게임 안 메뉴, 저장 키 `game:maze-level`): 쉬워요 / 어려워요 / 매우 어려워요. 별 보너스 +0/+1/+2(`G.win({bonus})`).
- **맵은 판마다 다르다**: 테두리 12가지(사각형·원·삼각형·마름모·오각형·육각형·하트·별·십자·팔각형·도넛·달) × 만드는 방식 8가지(구불구불·갈래갈래·방방이·오락가락·뒤죽박죽·옆으로 긴·위아래 긴·빙글빙글, 방방이는 사각형만) × 짝꿍 8가지(벽·바닥 색도 다름). 출발·도착은 길로 가장 먼 두 칸. 가로 화면은 왼쪽 세로 메뉴 + 오른쪽 큰 미로, 세로 화면은 위쪽 메뉴.
- **방해꾼**(모든 단계, 닿으면 처음부터 다시): 쉬움 2~3마리 / 어려움 5~6 / 매우 어려움 7~8. 🐛 떠돌이, 🕷️ 길목 지킴이(갈림길에서 옆길을 드나들며 길을 막는다), 🦂 추적자(가까우면 쫓아옴). 길로만 다니고 도착 칸·출발 칸 둘레 2칸에는 못 들어온다. 부딪힌 직후 1.5초 무적, 3번 이상 부딪히면 별 −1. 부딪힘은 **화면에 보이는 자리**로 따진다(방해꾼이 옆 칸에서 미끄러져 오는 중이면 절반을 넘어와야 부딪힘). 손가락이 벽 너머 칸에 닿아 돌아가는 길로 걸을 때는 방해꾼 앞에서 멈춘다.
- **음악**(`G.mazeMusic`, 레이싱 음악 `G.music` 과 별개): 웹오디오로 직접 연주하는 칩튠. 쉬움 4곡·어려움 4곡이 끊김 없이 이어지고, 매우 어려움은 1.1배 빠름. 🎵 버튼으로 음악만 끌 수 있다(저장 키 `game:maze:music`).
- 2026-11-07 단독 서비스 `arenarun23/miro`(허브 카드)에서 이 모음으로 옮겼다. 허브의 `/miro/` 주소는 `/game/#maze` 로 연결된다.

### 🧊 큐브 맞추기 (`js/games/cube.js`)
3×3×3 큐브를 **3D 입체**로 돌려 보고, 맞추는 법을 한 칸씩 따라 하는 시뮬레이터(초1 눈높이). `noSub: true` 로 자기 버튼을 쓴다.
- **조작**: 손가락으로 끌면 큐브 전체가 360도 돈다(트랙볼). 색깔 면을 살짝 누르면 그 면이 돈다(↻/↺ 버튼으로 방향 바꿈).
- **섞기**: 🐣 살짝(3번) / 🌀 많이(20번). **🎓 알려 줘!** 를 누르면 지금 상태에서 푸는 길을 계산해 한 번에 한 칸씩 보여 준다 — 돌릴 면만 밝게, 그 위에 도는 화살표, 필요하면 큐브가 스스로 돌아 그 면을 보여 준다. 👉 돌리기(또는 밝은 면 누르기) / ▶ 자동 / ↩ 뒤로 / ✖ 그만.
- **✋ 내가 할래!(직접 하며 확인)**: 화살표 없이 "가운데가 주황 면을 ↻ 오른쪽으로"처럼 지시만 보여 준다. 아래에서 방향(↺ 왼쪽 / ↻ 오른쪽)을 고르고 면을 누르면 맞으면 ⭕ 하고 다음으로, 틀리면 ❌(다른 면 / 방향 반대를 알려 줌) 하고 큐브를 되돌려 놓는다. 같은 칸에서 두 번 틀리거나 💡 힌트를 누르면 화살표·밝은 면이 나온다. 오른쪽 위에 ⭕·❌ 수, 끝나면 한 번에 맞힌 비율로 별(전부 ⭐3, 80% 이상 ⭐2, 그 밖 ⭐1).
- **📖 원리 보기**(큐브 칸 왼쪽 위 작은 버튼 `.cbhelp`, 자유 화면에서만 보임): 실제 큐브가 움직이며 보여 주는 5장 — ① 가운데 색이 면의 이름(가운데 칸만 환하게 + ○ 깜빡) ② 한 면을 돌리면 옆 줄도 같이 움직임(오른쪽 면 한 번 돌려 보임) ③ 한 층씩(하얀 층 → 가운데 줄 → 노란 층을 차례로 밝힘) ④ 공식은 돌렸다가 되돌림(`R U R'` 를 해 보이고 **바뀐 칸만 반짝**, 개수는 계산해서 말함) ⑤ 이제 해 볼까요. 슬라이드마다 읽어 주고(`G.speak`), ◀ 이전 / 다음 ▶ / 🔁 다시 보기(②④) / ✖ 닫기. 보기 전의 큐브 상태(섞은 것·기록)는 저장해 두었다가 닫으면 그대로 되돌린다. 돌리던 그림은 슬라이드를 넘기면 멈춘다(`gen` 토큰, `turn(q, ms, tok)` 이 상태를 안 바꾸고 끝남). 보는 동안 면을 눌러도 돌지 않고 끌어서 큐브를 돌리는 것만 된다.
- **면 이름 = 가운데 칸의 색**: 섞이면 한 면에 여러 색이 있으므로 "빨간 면"만으로는 헷갈린다. 안내는 "가운데가 ○○ 면" + 가운데만 그 색인 작은 그림으로 보여 주고, 큐브의 가운데 칸에는 ○ 표시(`.ctr`, 가운데 칸은 안 움직인다)를 둔다. 힌트·알려 줘!에서는 **돌릴 면의 스티커 9개만 환하게**, 같은 층의 옆 면 스티커 12개는 중간(`.d1`), 나머지는 많이 흐리게(`.d2`). 스티커는 **자기가 붙은 면** 기준으로 눌린다. 틀리면 "그건 가운데가 ○○ 면이에요"로 눌린 면을 알려 준다.
- **큐브 크기**: 큐브 칸(`.cbview`)의 가로 ÷ 5.0, 세로 ÷ 5.1 중 작은 쪽을 조각 한 변으로 쓴다(가만히 있을 때 칸의 약 88%). 크게 돌려 모서리가 칸을 2% 안팎 넘으면 칸 밖은 잘린다. 키울 때는 `node` 로 8가지 크기에서 큐브가 칸에서 차지하는 비율과 여러 자세에서 잘림을 재 본다.
- **🏋️ 공식 연습실**(`js/games/cube_lab.js`, 안내 칸 안 버튼 줄 `.cbtools`, 자유 화면에서만): 목표는 **어떤 큐브든 맞추는 공식 8개를 처음부터 익히는 것**. 공식 표 `FORMULAS`(`cube_core.js`)가 **🎓 알려 줘!(풀이)와 같은 공식**이다 — 풀이는 이 공식(+윗면 돌리기)만 쓴다(꼬마 춤 `R U R' U'`, 가운데 줄 좌·우, 노란 십자가, 노란 면, 모서리 자리, 마지막 가장자리; 하얀 십자가만 공식 없이 자유). 한 공식을 ① 보기(저절로 돌고 바뀐 칸만 반짝) → ② 따라 하기(화살표) → ③ 혼자 하기(색 칩·화살표 순서만) → ④ 외워서 하기(○○○ 점만) → ⑤ 써 보기(공식을 거꾸로 해서 망가뜨린 큐브를 공식으로 고침)로 익힌다. 틀리면 ❌ 하고 되돌리며 두 번 틀리거나 💡 힌트면 화살표. 보이지 않는 면이 필요하면 큐브가 스스로 돌아 보여 준다. 진도는 `G.store 'cube-lab'`(`{공식id: 끝낸 단계 수}`, 5면 ⭐ 익힘). 글자 R·U 대신 **색 칩 + ↻/↺** 로 보여 주고, 긴 공식(6번 초과)은 지금 차례 앞뒤 5개만 보인다. 이용 기록은 `aieduLog('use','cube-lab')` 한 번뿐(정답·입력 미기록). 연습실이 열리면 보기 전의 큐브(섞은 것)를 저장했다가 나갈 때 그대로 되돌린다.
- **자동 전체 화면**: 들어오면 `requestFullscreen`(주소창·아래 막대 숨김), 카드 누른 직후가 아니라 거절되면 첫 터치 때 한 번 더 시도, 나가면 `exitFullscreen`. 브라우저가 허락할 때만 되며 아이폰 사파리는 전체 화면 API 가 없어 안 된다(홈 화면에 추가하면 주소창 없이 열림). 가로·세로 모두. 스마트폰(터치 + 짧은 변 600px 미만)은 전체 화면이 된 뒤 `screen.orientation.lock('landscape')` 로 가로 고정하고 나갈 때 `unlock`(안드로이드 크롬 등 — 전체 화면일 때만 허락되며 아이폰은 안 됨). 위쪽 줄의 ⛶ 버튼(`#bar .right` 에 넣고 나갈 때 뺌)으로 켜고 끈다. 폭 420px 이하 폰에서는 이 버튼 때문에 위쪽 줄이 넘치지 않게 동그라미 버튼 44px·제목을 줄인다.
- **메뉴 버튼 자리**: 📖 원리·📂 내 기록·🏋️ 공식은 큐브 위에 띄우지 않고 안내 칸(`.cbinfo`) 안 가로 줄(`.cbtools`)에 둔다(큐브 모서리와 겹침 방지). 큐브 칸 크기는 그대로 두려고 자유 화면 안내 글을 한 줄로 줄였다 — 고칠 때는 10가지 크기에서 큐브 칸(`.cbview`) 높이가 이전보다 작아지지 않는지 잴 것.
- **글자 크기(기기에 맞춤)**: 큐브 화면에서만 `html[data-game=cube]{font-size:clamp(14px,min(3.7vh,4.9vw),30px)}` — 가로로 넓은 태블릿은 화면 높이를, 세로 폰은 폭을 기준으로 키운다(1280×800 에서 안내 글자 약 36px, 버튼 약 31px). 가로 화면 옆 칸은 `clamp(13rem,33vw,22rem)`. 10가지 크기에서 넘침 0·글자 잘림 0 확인(`scrollWidth>clientWidth` 버튼 수 0).
- **📂 내 기록**(안내 칸 안 버튼 줄 `.cbtools`, 자유 화면에서만): ① **이어하기 칸 10개** — ✋ 내가 할래! 도중 `✖ 그만` → "💾 저장하고 그만 / 그냥 그만 / ↩ 계속 하기". 저장하면 칸을 골라(`G.store 'cube-slots'`, 길이 10 배열: 큐브 54칸·⭕❌·한 개수 `done`·전체 `total`·시각) 저장하고, 빈 칸이 아니면 "덮어쓸까요?" 두 번 눌러야 덮어쓴다. 📂 에서 ▶ 이어하기 를 누르면 그 모양에서 풀이를 다시 계산해 이어 하고(⭕❌ 이어짐), 🗑 도 두 번 눌러야 지워진다. ② **📊 기록**(`G.store 'cube-rec'`, 최근 100개): 직접·따라서·거꾸로·혼자 맞춤·공식 익힘마다 시각/돌린 횟수/⭕❌를 남기고, 위에 맞춘 횟수·직접 횟수·최고 정확도·익힌 공식 수를 보여 준다. 모두 이 기기에만 저장하고 이용 기록(aieduLog)에는 보내지 않는다(`cube-resume` 사용 표시만).
- **다크 모드**: 폰의 '웹페이지 어둡게'가 켜져 있으면 하얀 면이 까맣게 바뀐다. 큐브 화면에서만 `html[data-game=cube]{color-scheme:only light}` 로 밝게 고정한다(`color-scheme:light` 만으로는 안 된다. 헤드리스 크롬 `--enable-features=WebContentsForceDark` 로 재현·확인). 다른 화면은 그대로.
- **푸는 방법**: 섞은 지 6번 이하면 "거꾸로 돌려서 맞추기"(⭐2), 아니면 초보자용 한 층씩 7단계(⭐3) — 하얀 십자가 → 하얀 모서리 → 가운데 줄 → 노란 십자가 → 노란 면 → 노란 모서리 자리 → 마지막 조각. 단계마다 정해진 공식(`F R U R' U' F'`, `R U R' U R U2 R'` 등)과 윗면 돌리기만으로 가장 짧은 조합을 찾는다(`bfs`: 따라가는 스티커 자리만으로 탐색). 평균 약 125번, 최대 약 180번 돌리기.
- **구조**: 모델은 스티커 자리 54칸 배열(`st[자리] = 스티커 번호`, 면 번호 = 번호/9)이고 돌리기 표(`PERM`)는 좌표 회전으로 자동 생성한다(손으로 쓴 표 없음). 화면은 CSS 3D(`preserve-3d`) 조각 27개 — 돌릴 때만 그 층 조각 9개에 회전을 주고 끝나면 상태를 바꿔 다시 칠한다. 애니메이션은 rAF(공통 CSS 가 `prefers-reduced-motion` 에서 transition 을 끄므로 CSS transition 에 기대지 않는다. 줄임 설정이면 바로 바뀜).
- **시험**: `js/games/cube_core.js`(모델·풀이·`FORMULAS`, 화면 없음)를 노드에서 불러 무작위로 섞은 1000판이 모두 풀리는지 확인했다. 풀이를 고치면 다시 돌릴 것.

### 🏁 레이싱 (`js/games/race.js`, 데이터 `race_data.js`)
- **👥 선수 수**: 경기장 고르기(3단계)에서 2·4·6명(나 포함)을 고른다. 모든 경기장 공통, `G.store 'race:nr'`(기본 6). 아이템은 등수 대신 '뒤에서 몇 번째쯤인지'(비율)로 나눈다. 가로 화면은 제목 줄에, 세로 화면은 탭 아래 줄에 둔다.


## 게임 추가하는 법
1. `js/games/새게임.js` 작성: `G.register({ id, name, desc, icon, cat: 'draw'|'match'|'play', color: 'pink|sky|orange|mint|lemon|lilac|peach', start(root){ …; return 정리함수 } })`
   - `variants` 에 종류 수를 적으면 코어가 섞어서 `v` 로 넘겨 준다. 격자는 `G.bestGrid(n, box)` 로 정한다.
   - 끝나면 `G.win({ stars: 1~3, text })` 를 부른다. 타이머는 반환하는 정리함수에서 해제한다.
2. `index.html` 에 `<script src="js/games/새게임.js"></script>` 추가 (`main.js` 앞).
3. 카테고리를 늘리려면 `js/core.js` 의 `G.cats`.
